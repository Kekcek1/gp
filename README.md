# Призраки Везенбергского квартала

Визуальная новелла на Ren'Py 8.5: пять серий, 112 сцен, 91 меню, 2 916 реплик,
три финала.

- **Сайт:** https://kekcek1.github.io/gp/
- **Игра в браузере:** https://kekcek1.github.io/gp/play/
- **Пять вариантов интерфейса:** https://kekcek1.github.io/gp/concepts/
- **Релизы APK / Windows / Web:** https://github.com/Kekcek1/gp/releases/latest
- **Исходники Ren'Py:** ветка [`source`](https://github.com/Kekcek1/gp/tree/source)

## Ветки

- `main` — лендинг, игра в `/play/` и галерея концептов `/concepts/`.
- `source` — исходный Ren'Py-проект, инструменты сборки и проверок.

## Что изменено

- Сюжет оригинала сохранён; внесены только орфографические и грамматические правки.
- Из меню игры убран пункт «Серии».
- Звук по умолчанию — 50%.
- Интерфейс адаптируется под экран; для портретной ориентации есть подсказка поворота.
- Веб-сборка использует progressive download: `game.zip` около 7 МБ.
- Runtime-изображения дедуплицированы по SHA-256.
