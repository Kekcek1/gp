# Игровая вселенная

Личный хаб проектов и браузерных игр. Главная страница ведёт в два проекта:

| Проект | Что внутри | Вход |
|---|---|---|
| **Новела** | «Призраки Везенбергского квартала» — визуальная новелла, 5 серий, 3 финала | [`novela/`](novela/) |
| **Яндекс Игры** | Каталог из четырёх браузерных игр | [`yandex/`](yandex/) |

## Игры каталога

| № | Название | Жанр | Папка |
|---|---|---|---|
| 01 | **Pulsebound** | неоновая аркада на одну кнопку | [`yandex/pulsebound/`](yandex/pulsebound/) |
| 02 | **Сияние рифа** / Reef Glow | головоломка «три в ряд» | [`yandex/reef-glow/`](yandex/reef-glow/) |
| 03 | **Астрощит** / Astroshield | космическая аркада-оборона | [`yandex/astroshield/`](yandex/astroshield/) |
| 04 | **Звездолов** / Starhook | атмосферная рыбалка | [`yandex/starhook/`](yandex/starhook/) |

## Структура

```text
index.html              главная: выбор проекта
yandex/index.html       каталог игр с фильтрами
novela/                 сайт новеллы 2.0.0 (копия без изменений)
yandex/pulsebound/      игра 1 — runtime-файлы
yandex/reef-glow/       игра 2 — runtime-файлы
yandex/astroshield/     игра 4 — runtime-файлы
yandex/starhook/        игра 5 — runtime-файлы
assets/                 общие стили, скрипты, шрифты, обложки
server.mjs              локальный статический сервер
```

## Локальный запуск

Нужен Node.js 18+:

```powershell
node server.mjs
```

Открой `http://127.0.0.1:8080/`. Сервер поддерживает range-запросы — это важно
для `renpy.data` и больших игровых файлов.

## Публикация

Сайт рассчитан на GitHub Pages из корня ветки `main`:

1. Settings → Pages → Build and deployment → **Deploy from a branch**.
2. Branch: `main`, folder: `/ (root)`.
3. Файл `.nojekyll` уже добавлен — он отключает обработку Jekyll.

Адрес проекта: `https://kekcek1.github.io/gp/`.

## Важно про Яндекс SDK

Игры подключают `/sdk.js` по абсолютному пути — так требует платформа Яндекс Игр.
На GitHub Pages этого файла нет, поэтому при запуске сайта игры автоматически
переходят в локальный режим: прогресс сохраняется в `localStorage`, реклама и
облачные сохранения отключены. Это ожидаемое поведение, а не ошибка.
