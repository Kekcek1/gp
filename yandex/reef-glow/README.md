# Сияние рифа / Reef Glow

Уютная браузерная головоломка «три в ряд» для Яндекс Игр. 60 уровней, 6 глав, волна света, особые фишки, ежедневный подарок, достижения, магазин усилителей и рейтинг.

Проект полностью готов к загрузке: `build/reef-glow-v1.0.0.zip`. Все тексты, иконки, обложки, скриншоты и видео лежат в `promo/` и `docs/`.

## Быстрый запуск

```powershell
cd "G:\01_Проекты\Игры\05_Яндекс_игры\2"
node tools\serve.cjs 8124
```

Открыть `http://127.0.0.1:8124/`. Сервер отдаёт локальную заглушку `/sdk.js` из `tests/sdk-stub.js`, чтобы можно было проверить рекламу, авторизацию и облако без платформы.

Без SDK игра тоже работает: откройте `index.html` через любой статический сервер без `/sdk.js` — включится локальный режим. Именно так проверен распакованный архив.

> `sdk.js` никогда не кладётся в архив: на Яндекс Играх платформа отдаёт его по относительному пути `/sdk.js`.

## Управление

- **Телефон:** тап по фишке, затем по соседней; можно провести пальцем между соседними фишками.
- **Мышь:** то же самое.
- **Клавиатура:** стрелки — выбрать клетку, Enter/пробел — выбрать/поменять, Esc — пауза.
- Кнопка «Волна» активируется при 100% заряда: нажмите её, затем любую фишку — весь цвет исчезнет.
- Усилители: молоток, перемешивание, +3 хода, заряд волны.
- Звук и язык — в настройках; музыка/SFX отключаются отдельно.

## Что реализовано

- 60 детерминированных уровней в 6 главах с ростом сложности и калиброванными порогами звёзд.
- Match-3 с каскадами, спецфишками (луч, бомба, радуга), комбо и волной.
- Тина, которая очищается совпадениями рядом; цели «собери» и «очисти».
- Мета: звёзды, монеты, магазин, ежедневный подарок, 10 достижений, карта глав.
- Локальный и облачный прогресс, гостевой вход, Яндекс ID по кнопке.
- Лидерборд по сумме звёзд; при отсутствии лидерборда — понятное сообщение.
- Реклама только через SDK: fullscreen в логических паузах, rewarded по желанию.
- Автоопределение языка RU/EN, ручной переключатель, автосохранение настроек.
- Адаптив: портрет/альбом, 390×844 … 1600×900, ограничение 2:1 на ультрашироких экранах.
- Canvas 2D, процедурная графика и WebAudio, без внешних файлов и сетевых запросов.
- ~60 FPS на десктопе и мобильном эмуляторе (замеры в QA).

## Структура

```
index.html                 точка входа
css/style.css              оформление, адаптив
js/core.js                 чистое игровое ядро (без DOM)
js/levels.js               60 уровней и главы
js/i18n.js                 RU/EN строки
js/sdk.js                  обёртка Yandex Games SDK + локальный fallback
js/save.js                 прогресс, облако, достижения, ежедневный подарок
js/audio.js                WebAudio: музыка и SFX
js/render.js               Canvas: фон, поле, фишки, частицы
js/ui.js                   экраны, модальные окна, HUD
js/game.js                 контроллер уровня, анимации, реклама, пауза
js/main.js                 загрузка и порядок инициализации
assets/fonts/              Nunito (OFL) + лицензия
assets/favicon.png
tools/                     сборка, проверка, скриншоты, видео, dev-сервер
tests/                     юнит, E2E, статические проверки, симуляция
docs/                      анализ, публикация, тексты, QA, ассеты
promo/                     иконка, обложки, скриншоты, видео
build/                     готовый ZIP
```

## Сборка архива

```powershell
python tools\build_zip.py
python tools\verify_archive.py
```

Результат: `build/reef-glow-v1.0.0.zip`, 16 файлов, 0,372 МБ распаковано, 0,138 МБ ZIP, `index.html` в корне, имена ASCII без пробелов.

## Тесты

```powershell
node --test tests\core.test.cjs      # 15/15
node tests\check-static.mjs          # ключи, id, ссылки, actions
node tests\levels-sim.cjs 20         # симуляция баланса
```

E2E требует запущенный `tools/serve.cjs 8124` и Chrome с CDP на `9222`:

```powershell
node tests\e2e.mjs                   # 55 проверок
```

Подробности и результаты — в `docs/QA.md`.

## Публикация

Пошаговый чек-лист — `docs/PUBLISHING.md`. Готовые тексты — `docs/STORE_TEXTS.md`. Анализ площадки и решения — `docs/ANALYSIS.md`. Промоматериалы — `docs/ASSETS.md`.

Коротко: загрузить ZIP, выбрать Desktop + Mobile (не ТВ), ориентация «Любая», языки RU/EN, возраст 0+, категории «Головоломки»/«Три в ряд», включить облачные сохранения, рекламу и стики-баннер, создать лидерборд `reef_stars`, загрузить иконку/обложки/скриншоты/видео.

## Лицензии

Код, графика, уровни, тексты и звук созданы для этого проекта. Шрифт Nunito распространяется по SIL Open Font License 1.1; текст лицензии — `assets/fonts/OFL.txt`. Сторонних ассетов, библиотек и сетевых запросов нет.

## Ограничения

- Нет ТВ-пульта, геймпада и инап-покупок.
- Один лидерборд; создаётся в Консоли.
- Языки RU/EN.
- Облако доступно на Яндекс Играх; вне платформы — локально.
- Fullscreen API на iOS может быть недоступен; геймплей от этого не зависит.
