# Публикация в Яндекс Играх

Пошаговая инструкция для Консоли разработчика. Все значения для полей — в `DRAFT.md`.

## 1. Что загружаем

- Архив: `dist/starhook-yandex.zip`.
- В корне архива — `index.html`.
- Внутри: 19 файлов, ~130 КБ, без `sdk.js`, `dev/`, `tools/`, `tests/`, `store/`.
- Платформы: Десктоп, Мобильные (Android, iOS).
- Ориентация: Любая.
- Языки: русский, английский, турецкий.
- Возраст: 0+.
- Инап-покупки: нет.
- Облачные сохранения: да.
- Реклама: rewarded + редкий interstitial.

Пересобрать архив:

```bat
node tools/build.mjs
```

`dist/BUILD_REPORT.txt` покажет состав, размер, SHA-256 и проверки.

## 2. Регистрация и черновик

1. Войдите в [Консоль разработчика](https://games.yandex.ru/console) с аккаунтом разработчика.
2. Заключите договор по единой лицензионной схеме, если ещё не сделали этого.
3. Нажмите **Добавить игру**.
4. Заполните вкладку **Черновик**:
   - **Версия:** `1.0.0`.
   - **Архив:** `dist/starhook-yandex.zip`.
   - **Поддерживаемые платформы:** Десктоп; Мобильные → Android, iOS.
   - **Ориентация:** Любая.
   - **Игра переведена на:** русский, английский, турецкий.
   - **Возрастной рейтинг:** 0+.
   - **Категории:** Казуальные; Симуляторы.
   - **Теги и ключевые слова:** из `DRAFT.md`.
   - **Облачные сохранения:** включить.
   - **Инап-покупки:** не добавлять.
   - **Комментарий разработчика:** из `DRAFT.md`.
5. Для каждого языка (RU/EN/TR) заполните «Название», «SEO-описание», «Об игре»,
   «Короткое описание», «Как играть» и загрузите соответствующие медиа.

## 3. Лидерборд

Перед отправкой на модерацию создайте лидерборд:

- Раздел: **Лидерборды** в Консоли.
- Техническое имя: `starhook_score`.
- Тип: **numeric**.
- Сортировка: по убыванию (больше — лучше).
- Название: «Звездоловы» / «Starhooks» / «Yıldız Avcıları».
- Формат: целое число (очки звездолова).

Если лидерборд не создан, `leaderboards.getEntries` вернёт 404; игра покажет
локальные рекорды без падения. После создания лидерборда функция включится
автоматически, обновление билда не нужно.

## 4. Реклама

В Консоли включите монетизацию через РСЯ:

- **Rewarded video** — на карточке улова, по кнопке «Удвоить».
- **Interstitial** — только при возврате в меню после 3 минут игры, не чаще
  ограничений платформы.

В коде уже реализованы:

- пауза звука и игры на `onOpen`;
- возобновление на `onClose`/`onError`;
- `GameplayAPI.stop/start` вокруг рекламы;
- защита от повторного показа;
- отсутствие рекламы во время активного вываживания.

Если реклама не нужна, её можно отключить в Консоли — игра продолжит работать,
кнопка удвоения будет скрыта при недоступности SDK.

## 5. Медиа

Загружайте для каждого языка свои файлы:

| Материал | RU | EN | TR |
|---|---|---|---|
| Иконка 512×512 | `icon-512.png` | same | same |
| Maskable | `icon-maskable-512.png` | same | same |
| Обложка 800×470 | `cover-ru-800x470.png` | `cover-en-800x470.png` | `cover-tr-800x470.png` |
| Витрина 1560×520 | `hero-ru-1560x520.png` | `hero-en-1560x520.png` | `hero-tr-1560x520.png` |
| Скриншоты desktop | `screenshot-desktop-*-ru.png` | `...-en.png` | `...-tr.png` |
| Скриншоты mobile | `screenshot-mobile-*-ru.png` | `...-en.png` | `...-tr.png` |
| Видео 16:9 | `starhook-trailer-1920x1080-ru.mp4` | `...-en.mp4` | `...-tr.mp4` |

Скриншоты: 5 десктопных 16:9 (1920×1080) и 4 мобильных 9:16 (1080×1920).
Иконка и обложка без текста на иконке; обложки локализованы.

## 6. Самопроверка перед модерацией

- [ ] Архив собран заново после последних правок.
- [ ] В корне ZIP только один `index.html`.
- [ ] В именах файлов нет пробелов и кириллицы.
- [ ] `sdk.js` не лежит в архиве.
- [ ] SDK подключается как `/sdk.js`.
- [ ] `LoadingAPI.ready()` вызывается после готовности меню.
- [ ] `GameplayAPI.start/stop` видны в debug-панели.
- [ ] Язык меняется через SDK mocks на RU/EN/TR.
- [ ] Звук останавливается при сворачивании, потере фокуса и рекламе.
- [ ] Контекстное меню не появляется в игровой области.
- [ ] Rewarded и interstitial не ломают игру.
- [ ] Сохранение переживает перезагрузку и очистку кеша.
- [ ] Игра проходится до финала; свободная игра работает.
- [ ] Все кнопки в меню, магазине, коллекции, журнале, карте и настройках работают.
- [ ] Скриншоты и видео соответствуют текущему билду.
- [ ] Медиа загружены на всех трёх языках.
- [ ] Комментарий модерации заполнен.
- [ ] Лидерборд `starhook_score` создан.

## 7. Тестирование в черновике

1. Откройте черновик кнопкой **Открыть с debug-панелью**.
2. В debug-панели проверьте индикатор SDK:
   - `IT` — SDK инициализирован корректно;
   - `W` — ожидание;
   - `IF` — старый загрузчик (не должно быть).
3. Откройте **SDK mocks** ⚒️ и по очереди выберите RU/EN/TR — игра должна
   перезапуститься на выбранном языке.
4. Проверьте **Game Ready**, **Gameplay**, **Pause/Resume** в debug-панели.
5. Нажмите **Clear cloud data** ☁️ и проверьте, что игра начинает новую историю.
6. Проверьте показ rewarded/interstitial (списаний не будет).
7. Пройдите первые 5–10 минут: заброс, поклёвка, вываживание, магазин, задания,
   карта, коллекция, сохранение.
8. Проверьте на телефоне: портрет, альбом, сворачивание, возврат.
9. Проверьте в Chrome, Яндекс Браузере, Firefox, Safari (если доступны).

## 8. Отправка и релиз

1. Нажмите **Отправить на модерацию**.
2. Модерация обычно занимает 3–5 рабочих дней.
3. При отказе: исправьте замечания, пересоберите архив, загрузите новую версию.
4. После одобрения игра публикуется автоматически (или по кнопке при отсроченной
   публикации).
5. После релиза подключите аналитику и следите за D1/D7, оценкой и ошибками.

## 9. Обновления

- Меняйте `version` в черновике.
- Пересобирайте ZIP через `node tools/build.mjs`.
- Обновляйте скриншоты, если изменился интерфейс.
- Не меняйте основную концепцию игры в обновлении (п. 1.24 требований).
- После изменения промо-материалов может потребоваться контентная модерация.
