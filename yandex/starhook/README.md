# ЗВЕЗДОЛОВ / STARHOOK

**Атмосферная рыбалка на краю ночного неба для Яндекс Игр.**

Тихая заводь, тёмное небо и одна удочка. Ловите светящихся рыб, открывайте 48 видов,
возвращайте шесть погасших созвездий и раскройте историю старого смотрителя Орлина.

![Геймплей](store/screenshot-desktop-1-frozen-ru.png)

## Что это

«Звездолов» — законченная браузерная игра в жанре casual / fishing simulator:
короткие сессии по 2–5 минут, понятное управление одним пальцем, коллекция,
сюжетная кампания на 10+ минут и спокойный темп без таймеров и штрафов.

Всё создано с нуля: код, графика, музыка, звуки, тексты и локализация.
Внешних ассетов, шрифтов, изображений и сетевых запросов нет.

- **6 локаций** с собственными палитрами, погодой и созвездиями.
- **48 видов рыб**: от обычных плотвичек до шести легендарных хранителей.
- **14 глав сюжета** с письмами смотрителя, знамениями и финалом.
- **24 достижения**, ежедневные задания, подарок дня и серия входов.
- **4 ветки улучшений** снастей и **5 наживок**.
- **Коллекция** с описаниями, рекордами веса и «новыми» видами.
- **Рейтинг** через лидерборды Яндекс Игр и облачные сохранения.
- **Русский, английский и турецкий** языки с автоопределением через SDK.
- **Реклама**: rewarded за удвоение улова и редкий interstitial на естественной паузе.

## Как запустить

Игре нужен локальный HTTP-сервер: ES-модули и `/sdk.js` не работают через `file://`.

```bat
cd /d G:\01_Проекты\Игры\05_Яндекс_игры\5
node tools/serve.mjs
```

Откройте <http://127.0.0.1:8125/>. Локальный сервер отдаёт игру и подменяет
`/sdk.js` имитацией Yandex Games SDK (см. `dev/sdk.js`).

Для проверки языка: `?lang=ru`, `?lang=en`, `?lang=tr`.
Для отладки на локальном сервере: `?debug=1` (открывает `window.__STARHOOK__`).

## Управление

| Действие | Мышь / телефон | Клавиатура |
|---|---|---|
| Заброс | зажать круглую кнопку и отпустить в золотой зоне | `Space` |
| Подсечка | тап/клик в момент поклёвки | `Space` |
| Вываживание | удерживать кнопку, отпускать при высоком натяжении | `Space` |
| Пауза / закрыть окно | кнопка паузы / `Esc` | `Esc` |
| Наживка | карточка наживки внизу | — |

Игра корректно работает в портретной и альбомной ориентации, на телефоне и десктопе.
Есть «мягкий режим» и уменьшение движения для доступности.

## Проверки

```bat
node --test tests/core.test.js      :: 19 юнит-тестов ядра и данных
node tools/check-i18n.mjs           :: 283 ключа × 3 языка, данные рыб/квестов
node tests/e2e.mjs                  :: полный браузерный сценарий (Chrome)
node tests/extra.mjs                :: ежедневки, подарок, достижения, финал, турецкий
node tools/build.mjs                :: production-архив и проверки
```

E2E-тесты сами поднимают локальный сервер и используют headless Chrome/Edge.
Скриншоты проверок складываются в `screenshots/`.

## Сборка для Яндекс Игр

```bat
node tools/build.mjs
```

Результат:

- `dist/game/` — распакованная production-версия;
- `dist/starhook-yandex.zip` — архив для загрузки в Консоль разработчика;
- `dist/BUILD_REPORT.txt` — состав, размер, SHA-256 и результаты проверок.

Архив содержит только `index.html`, `css/`, `js/` и пустую `assets/`.
Локальный `sdk.js`, `dev/`, `tools/`, `tests/`, `screenshots/` и `store/` в архив не попадают.

В `store/`:

- `icon-512.png` — иконка 512×512.
- `icon-maskable-512.png` — маскируемая иконка с безопасной зоной.
- `cover-ru-800x470.png`, `cover-en-800x470.png`, `cover-tr-800x470.png` — обложки.
- `hero-ru-1560x520.png`, `hero-en-1560x520.png` — обложки на витрину.
- `screenshot-desktop-*-ru/en/tr.png` — 5 скриншотов 1920×1080 на каждом языке.
- `screenshot-mobile-*-ru/en/tr.png` — 4 скриншота 1080×1920 на каждом языке.

Генерация:

```bat

```

Для генерации ассетов нужны локальный сервер и `ffmpeg-static` (уже установлен
в `node_modules`, в архив не входит).

## Технические детали

- Чистый HTML/CSS/JavaScript, без сборщика и фреймворков.
- Canvas 2D для сцены и рыб, SVG для иконок, WebAudio для звука.
- Все изображения и звуки генерируются в рантайме; папка `assets/` пуста.
- Размер production-архива: ~130 КБ (лимит Яндекс Игр — 100 МБ).
- `localStorage` + облако `player.setData` (ключ `starhook_save`).
- Yandex SDK: `LoadingAPI.ready`, `GameplayAPI.start/stop`, `environment.i18n.lang`,
  `player.getData/setData`, `adv.showRewardedVideo`, `adv.showFullscreenAdv`,
  `leaderboards.setScore/getEntries`, `auth.openAuthDialog`.
- Звук останавливается при потере фокуса, сворачивании вкладки и во время рекламы.
- Контекстное меню отключено в игровой области.
