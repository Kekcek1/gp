# Анализ Яндекс Игр и обоснование концепции

Дата анализа: ноябрь 2026.

## 1. Что проверено

- Полные требования к играм: технические, UX, контент, реклама, локализация.
- Документация SDK: подключение, Game Ready, GameplayAPI, язык, данные игрока,
  реклама, лидерборды, авторизация, пауза/возобновление.
- Требования к черновику: название, SEO-описание, «Об игре», «Как играть»,
  иконка 512×512, обложка 800×470, витрина 1560×520, скриншоты 16:9 и 9:16,
  видео 16:9 до 28 секунд.
- Витрина и подборки Яндекс Игр, обзоры рынка 2025–2026, страницы конкурентов
  в жанре рыбалки.
- Частые причины отклонения на модерации.

## 2. Рынок и жанры

По данным витрины и обзоров:

- Каталог — около 19 000 игр; в 2025 году опубликовано около 24 000, снято 29 000.
- Самые массовые жанры: казуальные, три-в-ряд, bubble shooters, аркады,
  головоломки, симуляторы, merge, стратегии.
- В топе 2026: короткие аркады («Укради Яйцо!», «Клавишный побег»), песочницы,
  стрелочные головоломки, merge, три-в-ряд, пасьянсы.
- Растёт мидкор: стратегии, RPG, сложные симуляторы, гибридная монетизация.
- Мобильный и десктопный трафик сопоставимы; кроссплатформенность и портретный
  режим важны.
- Высокая конкуренция в рыбалке: есть проекты с 20 локациями, 120–250 видами,
  кейсами, рынком и глобальным рейтингом. Чтобы выделиться, нужна не «больше рыбы»,
  а свой мир и эмоция.

## 3. Конкурентный анализ рыбалок

| Игра | Сильные стороны | Что берём | Чем отличаемся |
|---|---|---|---|
| Fishing Place | 250+ видов, 24 локации, кейсы, рейтинг | коллекция, рейтинг, простой заброс | ночное небо, созвездия, нет кейсов и покупок |
| Russian Fishing New | атмосфера, снасти, навыки, квесты | атмосфера, прогрессия снастей | фэнтези-мир, короткие сессии, нет энергии |
| Аномальная рыбалка | постапокалипсис, ивенты, крафт | ивентовость, коллекция | светлая уютная эстетика, без хоррора |
| Рыбалка (Vetur) | 20 локаций, 120 видов, день/ночь | локации и рекорды | 6 рукотворных локаций с сюжетом |
| Star Fishing (Roblox) | звёзды вместо рыбы, редкость | космическая метафора | оригинальный мир, браузерная игра, сюжет |

Вывод: **космическая рыбалка с восстановлением созвездий** — свободная ниша,
которая объясняет, зачем ловить рыбу, и даёт визуально сильную обложку/трейлер.

## 4. Целевая аудитория

- 16–45 лет, играют в браузере на телефоне в перерыве или на десктопе вечером.
- Любят уютные игры, коллекции, рыбалку, «магию», спокойный темп.
- Не хотят таймеров, энергии, обязательных покупок и сложного обучения.
- Ценят понятный прогресс и возможность вернуться через день.

## 5. Требования платформы → решения

| Требование | Решение в игре |
|---|---|
| SDK встроен | `<script src="/sdk.js">` + `YaGames.init()` |
| Game Ready | `LoadingAPI.ready()` после готовности меню |
| GameplayAPI | start/stop на входе в игру, модалках, паузе, рекламе, вкладке |
| Автоязык | `ysdk.environment.i18n.lang` на старте; RU/EN/TR |
| Гостевой вход | игра без входа, local + cloud, авторизация только по кнопке |
| Облачные сохранения | `player.setData/getData`, ключ `starhook_save`, `updatedAt` |
| Звук вне игры | `visibilitychange`, `blur`, `game_api_pause`, AudioContext.suspend |
| Звук в рекламе | pause/resume на callbacks SDK + `game_api_pause` |
| Контекстное меню | `contextmenu` отключён в `#app` |
| Завершённый вид | 14 глав, финал, 48 рыб, 6 локаций, все кнопки работают |
| >10 минут | сюжет 1,5–3 часа + коллекция и ежедневки |
| Архив ≤100 МБ | ~130 КБ, 19 файлов, без внешних ассетов |
| index.html в корне | да |
| Без пробелов/кириллицы в именах | проверяется `tools/build.mjs` |
| Скриншоты | 5 десктопных 1920×1080, 4 мобильных 1080×1920 на каждом языке |
| Видео | 27,5 с, 1920×1080, H.264 + AAC |
| Реклама | rewarded + редкий interstitial, звук на паузе |
| Лидерборд | `starhook_score`, создаётся в Консоли |
| Возраст | 0+, без насилия и азартных механик |

## 6. Частые причины отказа и профилактика

1. **SDK подключён неправильно.** Используется относительный `/sdk.js`; в архив
   не попадает локальная имитация; `init()` вызывается ровно один раз.
2. **Нет Game Ready.** Меню показывается только после загрузки; `ready()` вызывается
   после фактической готовности, не по таймеру.
3. **Язык не определяется.** `i18n.lang` читается до меню; все три языка проверены.
4. **Звук не останавливается.** Реализованы blur/visibility/SDK-пауза, реклама и
   `AudioContext.suspend`.
5. **Системное контекстное меню.** Отключено в игровой области.
6. **Незавершённый контент.** Есть финал, свободная игра, коллекция, все экраны.
7. **Скриншоты не отражают игру.** Сделаны из реального билда, 70%+ геймплея.
8. **Дубликат/чужое название.** «Звездолов» и «Starhook» проверены по поиску
   Яндекс Игр; точного совпадения в каталоге не найдено.
9. **Язык черновика не совпадает с билдом.** Черновик и игра заявляют RU/EN/TR.
10. **Реклама во время геймплея.** Rewarded — только на карточке улова,
    interstitial — только при переходе в меню после 3 минут.

## 7. Ключевые метрики после релиза

- D1/D7 retention: ежедневные задания, подарок, коллекция.
- Средняя длительность сессии: 3–8 минут.
- Конверсия в первый улов: обучение и быстрый первый заброс.
- Доля игроков, открывших 2-ю локацию: сюжетный темп.
- Оценка игры: стабильность, отсутствие ошибок, понятность.
- Рейтинг: общий счёт и коллекция.
