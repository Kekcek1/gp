# Pulsebound

**Pulsebound** — неоновая аркада на одну кнопку для Яндекс Игр. Комета летит по двум орбитам пульсара, игрок перескакивает между ними, уклоняется от астероидов, собирает звёзды и заполняет шкалу импульса. Бесконечный забег, секторы с разными палитрами, ежедневные задания, подарок дня, восемь кометных следов и лидерборд.

- Версия: **1.0.0**
- Платформы: **Desktop + Mobile**
- Ориентация: **любая**
- Языки: **русский, английский, турецкий** (автоопределение через SDK)
- Технологии: **HTML5 Canvas 2D + vanilla JavaScript**, без внешних ассетов
- Все графика и звук создаются процедурно в браузере

## 2. Управление

| Действие | Управление |
|---|---|
| Сменить орбиту | тап / клик / `Space` / `↑` / `↓` / `←` / `→` |
| Пауза | `Esc` / `P` / кнопка паузы |
| Звук | `M` / кнопки на экране |
| Продолжить после паузы | `Продолжить` / `Esc` |

Гостевой режим полностью играбелен, прогресс сохраняется локально. Вход с Яндекс ID предлагается только в разделе «Рейтинг» и объясняет преимущества.

## 3. Локальный запуск и тесты

Требуется Node.js и Chrome. В папке `tools/` уже установлены тестовые зависимости.

```powershell
cd "G:\01_Проекты\Игры\05_Яндекс_игры\1\tools"
node server.js
```

Откройте `http://127.0.0.1:8123/?lang=ru&auth=1&debug=1`.

- `/sdk.js` в тестовом сервере — это `tools/sdk-mock.js`: он имитирует `YaGames.init`, `LoadingAPI`, `GameplayAPI`, рекламу, игрока, облачные данные и лидерборд.
- Без mock-сервера игра тоже запускается: SDK недоступен, реклама и глобальный рейтинг скрываются, локальный прогресс работает.

Полезные query-параметры:

- `?lang=ru|en|tr` — язык SDK-мока;
- `?auth=0` — гость (проверка кнопки входа);
- `?ads=0` — ошибка рекламы (проверка fallback-сценария);
- `?debug=1` — открывает `window.__pbDebug` для QA.

## 4. Публикация в Яндекс Играх

### 4.1. Сборка архива

```powershell
cd tools
node build.js
```

Скрипт собирает `dist/pulsebound-1.0.0.zip` только из production-файлов (`index.html`, `css/`, `js/`, `assets/`), проверяет имена, размер и кладёт рядом `dist/SHA256.txt`. `tools/`, `store/`, `README.md` в архив не входят.

### 4.2. Черновик в Консоли

1. Войдите в [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console) с Яндекс ID.
2. «Добавить игру» → заполните черновик:
   - **Название:** `Pulsebound` на всех языках.
   - **Версия:** `1.0.0.0`.
   - **Архив:** `dist/pulsebound-1.0.0.zip`.
   - **Платформы:** Desktop, Mobile (Android, iOS).
   - **Ориентация:** Любая.
   - **Языки:** русский, английский, турецкий.
   - **Возрастной рейтинг:** 0+.
   - **Категории:** Аркады, Казуальные.
   - **Облачные сохранения:** включить.
   - **Монетизация:** включить (fullscreen + rewarded; sticky не используется).
3. Создайте лидерборд:
   - техническое имя: **`best_score`**;
   - тип: **numeric**;
   - сортировка: **DESC** (больше — лучше);
   - названия: «Рекорд» / «Best score» / «Rekor».
   Без этого лидерборд в игре покажет сообщение о недоступности, но игра и личные рекорды продолжат работать.
4. Загрузите промоматериалы из `store/`:
   - иконка `icon-512.png`;
   - обложка `cover-800x470.png`;
   - обложка на витрину `hero-1560x520.png` (опционально);
   - скриншоты Desktop и Mobile из `store/screenshots/`;
   - горизонтальное видео `store/video/pulsebound-trailer.mp4` (1280×720, 16:9, 16 с).
5. Тексты «Об игре», «Как играть», SEO и короткое описание — в `store/listing.md` (RU/EN/TR, все лимиты соблюдены).
6. В комментарии для модерации используйте готовый текст из `store/listing.md`.

### 4.3. Проверка в песочнице

- Откройте игру в Консоли с debug-панелью.
- Проверьте индикатор загрузчика (`IT`), `LoadingAPI.ready()` и `GameplayAPI.start/stop`.
- Проверьте рекламу: в черновике показываются тестовые блоки. Fullscreen вызывается кнопкой «Ещё раз» после 3-го завершённого забега (кулдаун 90 с), rewarded — только по кнопкам с подписью «Реклама».
- Проверьте облако: сыграйте забег, обновите страницу, прогресс должен сохраниться; кнопка очистки облака — в debug-панели.
- Проверьте авторизацию: гость → «Рейтинг» → «Войти с Яндекс ID»; после входа рекорд отправляется в `best_score`.
- Проверьте поворот экрана и изменение размера окна.

### 4.4. Отправка на модерацию

Обычно 3–5 рабочих дней. В игре нет внешних ссылок, сторонней рекламы, регистрации на сторонних сервисах и интерактивного ИИ. Все материалы созданы для этой игры.

## 6. Технические решения

- **Game Ready:** `LoadingAPI.ready()` вызывается после того, как меню отрисовано и интерактивно; загрузочный экран скрыт.
- **Gameplay API:** `start()` — старт/возобновление забега; `stop()` — пауза, смерть, меню, реклама, потеря фокуса.
- **Пауза платформы:** `game_api_pause`/`game_api_resume` ставят игру на паузу без лишнего меню и возобновляют после рекламы; ручная/системная пауза показывает панель.
- **Реклама:** звук и геймплей останавливаются; состояние забега сохраняется. Fullscreen — только в логической паузе после забега; rewarded — по явным кнопкам, награда не обязательна для игры.
- **Сохранения:** локально сразу, в облако с дебаунсом и `flush` на важных событиях; merge не теряет покупки и не дублирует валюту.
- **Лидерборд:** `ysdk.leaderboards.getEntries/setScore`, только для авторизованных; гостям доступны личные рекорды.
- **Адаптив:** игровое поле ограничено соотношением 2:1 на десктопе; интерфейс использует safe-area, `dvh`, внутренний скролл панелей.
- **Производительность:** DPR ≤ 2, кэш фоновых градиентов, предрендер glow-спрайтов, лимит частиц, режим «Низкие эффекты».
